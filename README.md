# Aura Portfolio

create a stunning, premium, mobile-first modeling portfolio website with a luxurious and editorial fashion aesthetic. The website should feel like a high-end Vogue, Dior, or Elite Model Management portfolio rather than a generic template.

Design Style:

Dark luxury theme with black, white, and gold accents.

Modern, minimal, elegant, and premium.

Smooth animations using Framer Motion.

Glassmorphism cards.

Large typography with bold headings.

Soft gradients and glowing effects.

Premium loading animation.

Rounded corners and floating UI.

Highly polished micro-interactions.

Important:
Design should be 100% mobile-first, optimized for phones (390px–430px width). The desktop version should simply scale from the mobile design. The entire layout should feel like a premium mobile app rather than a traditional desktop website.
